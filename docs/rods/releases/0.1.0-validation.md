## Limite da validação

A prévia não executa VS Code, JetBrains ou Zed. A conferência visual dentro
das três IDEs permanece pendente nesta entrega; não houve instalação nos
editores pessoais. Para concluir essa conferência, instale os entregáveis
conforme o README, selecione cada tema e abra `samples/typescript/themePreview.ts`.
